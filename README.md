# LifeLine+ Frontend Prototype

A responsive landing page built with plain HTML, CSS and JavaScript.

## Run locally

Open `index.html` in a browser. No build step or package installation is required.

Optional: use VS Code Live Server for a local development server.

## Included interactions

- Responsive navigation with mobile menu.
- Blood-group and component filters over clearly fictional demo listings.
- Donor-interest form with browser validation and local-only confirmation.
- Hospital/partner interest form with browser validation and local-only confirmation.
- CTA scrolling, accessibility labels, reduced-motion handling, and small-screen layouts.

## Important prototype notes

- This is only a frontend. It has no database, authentication, server, live inventory feed, map/geolocation integration, prescription upload/review, or delivery tracking backend.
- The sample blood listings and distances are fictional and must not be used for medical decisions.
- Form submissions are not transmitted or persisted. The success messages explicitly explain that.
- For a production health service, integrate verified hospital/blood-bank data, secure APIs, appropriate privacy and consent flows, and review with qualified medical, legal, and operational stakeholders.
